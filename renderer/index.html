AI provider

Use Gemini free-tier models or an OpenAI-compatible API.

Not configured

Defaults: Gemini 3.5 Transcribe Live for speech and Gemini 3.5 Flash Lite for answers. Both are listed on Google’s free tier; project quotas apply.

Gemini uses its native Live transcription and streaming text APIs. OpenAI-compatible providers use chat completions and audio transcriptions.

The desktop app encrypts your API key using Windows secure storage.

Answer quality, speed and transcription

Up to 100 terms, separated by commas or new lines. Gemini supports these hints; accuracy still depends on the recording. You can correct finalized wording in the transcript.

Balanced spends more reasoning on coding questions. Low-bandwidth mode retains a short audio lead-in but can miss quiet speech; Standard favors continuous capture. Reconnection buffers up to 8 seconds per source. Internet is required for cloud models. No automatic paid fallback.

Data-use policy

Unpaid practice mode excludes saved context and prior answers. Use only non-personal, non-confidential questions, images and audio. AI PDF upload and saved-session summaries are disabled in this mode. Reviewed mode is your confirmation that the provider/account terms permit the material; it does not change billing or guarantee privacy. Local mode only controls the app’s destination; check whether your local server calls a cloud service. Contact filtering is best effort and does not make private material suitable for unpaid services.

Local data and diagnostics

Checks the saved local model listing; it does not prove offline transcription or vision support.

Memory-only mode clears the saved workspace and its recovery copy when you save these settings. Current content stays in memory until the app closes. Export important sessions first. This is not forensic secure deletion.

Encryption covers resume/context, transcripts and answers in the workspace and recovery copy. Requires the original Windows user to decrypt; export before moving computers. Exports remain plaintext. Unknown legacy session dates are retained. Retention runs at startup and save; it does not remove the reusable context profile.

Up to 500 attempts from this app process, held in memory only: mode, network setting, stage timings and outcome. No transcript, screen, resume, key or raw error text. Speech end is estimated from audio activity; unavailable stages are left blank. Export includes failures and cancellations.

Screen-share privacy

Enabled by default on Windows. Applies to the workspace and floating copilot, and removes their taskbar buttons. Use Ctrl+Shift+M to bring the workspace back. Verify your meeting’s shared-screen preview before relying on it; OS dialogs and unsupported capture methods may remain visible.
